GitHub's AI coding agent that picks and combines models

GitHub Copilot Fusion takes the guesswork out of choosing AI models for coding. Instead of picking one model, Fusion automatically routes each task to suitable models and combines them when needed. One model can write code while another reviews or improves it. Choose Standard, High, or Max effort to balance speed, quality, and cost. Available across GitHub Copilot plans in VS Code, Copilot CLI, the Copilot app, and JetBrains IDEs.
