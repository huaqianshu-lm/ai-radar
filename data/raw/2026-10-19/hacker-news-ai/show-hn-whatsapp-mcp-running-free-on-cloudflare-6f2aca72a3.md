I wanted my humble Claude on mobile to access my WhatsApp messages but the only options I could find either required WhatsApp Business or an actual server to run Baileys on.
I wanted to run it for free on ClaudeFlare and with my personal WhatsApp account, so I built this.
Important feature - it connects to your Google account as well as WhatsApp to grab the names of all your WhatsApp contacts, otherwise you get only phone numbers for many of them and search doesn't work properly.
This is a single user install because it's both gray area and very private - so point your agent at the repo and let it set things up.
