Long-term memory for agents, across every harness

Harness Memory gives every harness agent its own long-term memory. Pick a memory engine (Mem0, Graphiti, Hindsight, ReMe, or your own) and plug it into different agent harnesses, like Claude Code, Codex and Hermes. Memory can be shared across agent harnesses, with fine-grained access control. Open source in Community Edition and available on HarnessRouter Cloud.
