Let your coding agent see inside your PyTorch model

Coding agents can read your PyTorch code, but they never see what actually flows through the model. tensorViz runs one real forward pass and turns it into an interactive graph with every module and tensor shape. Claude Code, Codex and Cursor can search that graph and read the measured shapes, so they fix model code from evidence instead of guesses. Or skip the install: the Model Explorer has graphs of 560+ models from recent papers to browse and discuss. Free and open source (MIT).
