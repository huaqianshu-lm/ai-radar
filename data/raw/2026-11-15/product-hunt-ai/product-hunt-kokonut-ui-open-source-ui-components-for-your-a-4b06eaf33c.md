Open-source UI components for your AI agent

Kokonut UI is a free, MIT-licensed library of 100+ React components made for coding agents. Connect through MCP in Claude Code, Cursor, VS Code or Codex, ask for "a tool approval card in my chat", and your agent finds the component, installs it and edits it in your repo. Every docs page is also served as Markdown for agents. This release adds 65 components and rebuilds 34, led by AI chat parts: tool calls, tool approval, diff review, citations and more.
