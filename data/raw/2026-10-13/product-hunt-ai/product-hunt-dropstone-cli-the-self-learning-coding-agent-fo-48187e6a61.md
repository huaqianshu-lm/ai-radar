The self-learning coding agent for your terminal

Dropstone CLI is a coding agent that learns from you. It reads your repo, edits across files, runs commands and tests, and checks its work before it says it's done. Correct it once and it keeps the lesson across sessions. Pick Fast, Pro, or Heavy models, plan before it builds, and set which commands run, ask first, or are blocked. Add skills, custom agents, parallel subagents, and MCP tools. Comment on a GitHub issue and it opens a pull request. On every plan, including Free.
