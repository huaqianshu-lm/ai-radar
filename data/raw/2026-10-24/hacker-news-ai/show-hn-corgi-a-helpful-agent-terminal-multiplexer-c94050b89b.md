Hey everyone,
Inspired by Herdr, I've built an agent multiplexer that I've been using as my daily driver for a few weeks now.
I think I improved on the concept in a few ways, focusing on the ergonomics I always wished I had:
I show you what the agents are up to, along with a running feed of their activity.
There's also a simple shortcut (F1) to go to the next unread agent.
I use multiple accounts, so I've added unified launcher for Codex/Claude Code/Pi.
Theres some careful ergonomics there: fast search and resume over sessions, inline usage tracking etc.
Many small quality of life improvements to the terminal experience:
- Links can be copied with a click, so no need to drag-select over many lines
- cmd+v just pastes images (even on SSH)
- images have a thumbnail preview.
- Built-in CPU/Memory/GPU usage tracking, broken down by workspace
I assume you have access to cheap inference (Luna/Haiku/etc).
It just reuses the agents to organize things for you: what is this http link? what is this worktree about? what is each agent doing? 
It's small but it made my environment feel more cozy.
On a personal note, I've been on a frustrating sick leave for a while now.
I created Corgi to challenge myself, and see if I can go back.
The answer is more mixed than I had hoped, but I am happy with the result and thankful for the experience.
I hope you like it! a few friends & myself have been using it for a few weeks and it's been pretty nice.
There's still a lot to improve and some rough edges, so feedback would be greatly appreciated.
Thank you :)
