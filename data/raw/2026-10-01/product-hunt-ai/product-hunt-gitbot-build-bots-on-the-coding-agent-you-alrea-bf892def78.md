Build bots on the coding agent you already use

GitBot turns a job you keep giving Claude Code, Codex or OpenCode into a bot. Write the instructions once, set what it may touch, and run it in any repo. Each run is a thread you can come back to. Install bots other devs made from the Library, or share yours with a code. ShipGuard, for example, reads your branch and says merge or block, with file and line evidence. Runs on your machine with the logins you already have. Open source. No account, no telemetry.
