open-source multiplayer AI for teams' coding agents

Agentmash is an open-source multiplayer AI for teams' coding agents, a shared context layer that tells every agent which files a teammate's agent is changing, so the agents talk to each other and work on their own without overwriting anyone's code. You can switch between tasks running on different models, @mention a teammate, your own agent or a teammate's agent like in Slack, and keep skills, chats and automations in sync. Connect Claude Code, Codex, Antigravity or your own open-source models
