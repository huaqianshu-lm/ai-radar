web-edit (
previously
) is my tiny web app for browsing and editing files in a folder. I mainly built it for editing files on different machines via Tailscale.
I added a "copy to clipboard" option for both text and image data. I needed this because I was running pelican prompts on a laptop from my phone (here's
DeepSeek 4.1 Flash 1017
) and I wanted an easy way to copy the resulting logs into a Gist.
